# DWINDLE

## Smart Energy Monitoring System

DWINDLE is a Flutter-based IoT application for real-time electricity consumption monitoring, energy cost estimation, carbon emission tracking, and energy usage analysis.

## Features

- Real-time electricity monitoring
- Smart meter and IoT integration
- Electricity tariff calculation
- Carbon emission tracking
- Energy usage history and analytics
- AI-powered energy assistance

## Tech Stack

- Flutter, Dart
- Firebase
- MQTT
- REST APIs
- ESP32
- PZEM-004T, ACS712, ZMPT101B

## Setup

1. Install Flutter and set up the development environment.

2. Clone the repository:

``` bash
git clone https://github.com/SivaSankari04/DWINDLE.git
cd DWINDLE
flutter pub get
(Configure the required credentials and services locally)
flutter run
```
Configuration
API credentials are excluded from this repository. To run the app fully, configure your own:
- Firebase configuration
- MQTT broker details
- AI service API key
Note:
This project is provided primarily as a reference for learning and development. It is not directly plug-and-play and requires the appropriate API credentials, IoT hardware, and configuration for full functionality.
